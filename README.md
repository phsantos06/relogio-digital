# Relógio Digital

Relógio digital com fundo de pôr do sol e painel de vidro, feito com HTML, CSS e JavaScript puro.

## Recursos
- **Relógio** com data por extenso, saudação por período do dia, formato 12h/24h e opção de ocultar segundos
- **Cronômetro** com centésimos e voltas (destaca a mais rápida e a mais lenta)
- **Temporizador** com atalhos (1, 5, 10, 25 min), tempo personalizado, anel de progresso e alarme sonoro
- Tela cheia, atalhos de teclado (Espaço e F), preferências salvas no navegador
- Responsivo e com suporte a `prefers-reduced-motion`
